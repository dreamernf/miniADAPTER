# miniADAPTER

## CAN-диагностика

Диагностическая прошивка выводит весь лог в USART2 (PA2 TX, PA3 RX), 115200 8N1.

При старте выполняется внутренний loopback-тест CAN-контроллера. Затем в обычном режиме раз в секунду отправляется STD-кадр `0x6FE` на 100 кбит/с. Для внешнего теста на шине должен быть ещё один активный CAN-узел с той же скоростью, иначе передатчик не получит ACK.

- `[CAN][SELFTEST] PASS` — CAN-периферия MCU, тактирование и программный путь работают.
- `[CAN][TX] ACK OK` — кадр реально вышел на шину и подтверждён другим узлом.
- `SELFTEST PASS`, но `ACK error` — в первую очередь проверить питание/режим CAN-трансивера, цепи TX/RX между MCU и трансивером, CANH/CANL, общую землю, терминацию и скорость шины.
- `[CAN][SELFTEST] FAIL` — искать проблему в MCU, тактировании, CAN-конфигурации или прошивке.

Принимаются и выводятся кадры с ID `0x2C1`, `0x2C3`, `0x5C1` и `0x320`. Статус со счётчиками TX/RX/ошибок печатается каждые 5 секунд.
